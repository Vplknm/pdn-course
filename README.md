## Запуск на Mac

Требуется Python 3.12. Установка зависимостей требует интернета.

```bash
git clone https://github.com/Vplknm/pdn-course.git
cd pdn-course/Программа_КМ2
python3.12 -m venv .venv
source .venv/bin/activate
python -m ensurepip --upgrade
python -m pip install -r requirements-lock.txt
python check_km2.py
```

Демонстрация с ручным вводом текста:

```bash
python -m pdn_course.demo
```

Для Windows и остальных команд см. инструкцию внутри программы.

## Что реализовано

Распознавание 16 типов ПДн: модель Natasha/Slovnet для ФИО, pymorphy3 для морфологического разбора, регулярные выражения и проверки контрольных разрядов для структурированных реквизитов.

Основной набор: 100 документов factRuEval2016 с добавленными синтетическими карточками реквизитов. Дополнительный набор: 120 синтетических текстов. Исходная разметка корпуса, лицензия MIT, происхождение данных и контрольные суммы включены.

Основной результат: BIO macro F1 **0.9408**, weighted F1 **0.9613**, без класса O в усреднении F1. В чистой среде пройдены 13 тестов. Подробности и ограничения оценки описаны в отчёте и инструкции.

Обезличивание, идемпотентность, сохранение морфологии замен и BERTScore относятся к следующему этапу КМ-3 и в этот комплект не входят.

## Сохранение следующих версий

Команды выполняются из папки `pdn-course` после изменения файлов:

```bash
git status
git add .
git commit -m "Описание изменений"
git push
```

История версий: `git log --oneline`. Для восстановления отдельного файла из выбранного коммита: `git restore --source=<хеш_коммита> -- "путь/к/файлу"`, затем сохраните восстановление новым коммитом.
